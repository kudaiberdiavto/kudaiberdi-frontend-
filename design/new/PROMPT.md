Продолжаем приложение «Кудайберген». Основные экраны, тема, компоненты и TabBar УЖЕ сделаны — не трогай и не переписывай их. Новые материалы лежат в папке design/new/. Сверстай только 11 новых экранов из неё и подключи их к API.

ЧТО В ПАПКЕ design/new/
- screens/*.png — эталонные скриншоты @2x (780×1688)
- html/*.html — разметка каждого экрана, все размеры в px, иконки inline SVG
- specs/*.json — все элементы с x, y, w, h, fontSize, fontWeight, color, background, radius, padding, shadow
- assets/services/*.svg + services.json — иконки 12 услуг и их коды (ServiceType)
- API_NEW.md — эндпоинты, поля и правила для этих экранов (если расходится с OpenAPI бэкенда — верен OpenAPI)

ПРАВИЛА ТОЧНОСТИ (как раньше)
- Экран 390×844, 1px макета = 1pt/1dp. Строку «9:41» не верстать (safe area). Рамка экрана — оформление макета: в specs из x и y вычитать 1.
- Значения брать из specs/html, не на глаз. Тексты дословно. Иконки — SVG без изменений.
- Использовать СУЩЕСТВУЮЩИЕ компоненты и тему: Button, Chip, BrandBadge, BrandChip, Segmented, BottomSheet, Avatar, PhotoTile, TabBar и т. д. Новый компонент — только если такого ещё нет.
- Фото в макете — заглушки: в коде Image с object-fit cover тех же размеров и радиусов.
